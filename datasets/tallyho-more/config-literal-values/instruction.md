load_config crashes with configparser's interpolation error when a value contains a percent sign, such as the shop name `Half % Off`, and it accepts settings that break the shop later. Read every value literally (`%` has no special meaning), and make every bad setting a ConfigError instead: a currency tallyho does not know (see `tallyho.money.MINOR_UNITS`), a `page_size` that is not a positive integer, and a tax rate that is not a number from 0 to 100. A bad tax rate's error message names its region.
