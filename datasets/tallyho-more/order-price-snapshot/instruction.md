Orders read back from the store are priced at each product's current price, so changing a product's price silently changes the totals of orders saved before. An order read from the store must keep the price, and the currency, each line had when the order was saved; the product's other fields (name, category, taxable) still come from the current product record. Store each line's currency in the order record as `currency`, next to `price`. Order records saved without a line price keep using the current product price, and ones with a price but no currency use the product's currency.
