The tracker

One chart per dataset, agent, model and arm. Each point is one run, in date order, labelled with the agent CLI's own version. Hover or focus a chart and use the arrow keys for the numbers.

Table view
Flags compare a run with the four before it in the same series: degraded when the run's Wilson upper bound is more than 15 points under the baseline rate, tool calls up when median tool calls exceed 1.5× the baseline's, recovered when a flagged series returns inside both. Runs with fewer than 12 valid sessions are marked low n and get no other flag. The av arm is Claude Code on the Scholion framework (hooks, a daemon and a workspace per task); its Δ columns are paired by task against the same day's cold run, with task-stratified 95% bootstrap intervals. No cell below 30 sessions carries a significance claim.
