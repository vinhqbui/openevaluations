The tracker

One chart per series: a dataset, agent CLI, model and harness, and an arm. Each point is one run, in date order, labelled with the agent CLI's own version. Hover or focus a chart and use the arrow keys for the numbers.

Each model is its own series. Tracker rows of different models are not comparable: a lower cost or a higher pass rate under another model says nothing about a CLI release. Charts and tables are grouped by model, the model leads every chart title, and nothing on this page pools, ranks or draws two models as one line. Since 2026-11-20 the tracker's legs (started by hand; the weekly schedule is off) run on claude-haiku-5-5: Claude Code cold, Claude Code on Scholion (av), OpenCode and goose. Before that it ran on deepseek-flash, with Codex in place of goose. The 2026-11-10 runs on deepseek-flash and deepseek-v4-pro (tallyho-cold, -more, -hard) are the tiers pilot below, not tracker legs. Within one model, the paired comparison is av against cold on Claude Code, same day; across CLIs the rows are a tracker, not a ranking (12 sessions a cell, below the 30 needed for any claim).
Table view, one table per model

Note on OpenCode's tokens: Harbor's OpenCode adapter leaves cache writes out of input and reasoning tokens out of output, though both are billed. Since 2026-11-20 the importer adds them back, so OpenCode's token columns count what the other CLIs' count. The published 2026-11-04 OpenCode rows (deepseek-flash) were imported before that and are not rewritten: their output and tokens billed leave out 21,053 reasoning tokens over 12 sessions (114 to 8,075 a session; median tokens billed 7,267.5 instead of 8,413.5). They had no cache writes to leave out. Their cost is OpenCode's own figure and is complete.

Note, 21 November 2026, added after seeing the results (exploratory, not pre-registered): in the 2026-11-20 av run on claude-haiku-5-5, every session was stopped once by Scholion's Stop hook after its final answer and asked to record what it had changed, and its first av record was refused because the summary was longer than a limit that release's hook text does not state. The pre-registration counts that step, so it is in the row. Scholion (called Margincode since 2026-11-12) now asks for the record before the final answer and no longer refuses a long summary on its main branch (open-margincode #93). No release has that change, and the tracker pins a release, so the row changes only when the pin does. Report of the run.

Note, 10 November 2026: our hard tier did not separate a cheap model from a costly one (pilot, 40 trials).

Flags compare a run with the four before it of the same dataset, agent, model and arm: degraded when the run's Wilson upper bound is more than 15 points under the baseline rate, tool calls up when median tool calls exceed 1.5× the baseline's, recovered when a flagged series returns inside both. Runs with fewer than 12 valid sessions are marked low n and get no other flag. The av arm is Claude Code on the Scholion framework (hooks, a daemon and a workspace per task); its Δ columns are paired by task against the same day's cold run, with task-stratified 95% bootstrap intervals. No cell below 30 sessions carries a significance claim.
