Datasets

Small, fixed task sets with hidden tests, so a weekly run stays cheap and two runs are comparable. Tasks are Harbor task directories in datasets/ of the repository.

tallyho-cold

Four one-file bugs in tallyho, a 25-file Python shop library written for benchmarking. One agent, cold start, hidden pytest files. The weekly tracker set.

handoff

The handoff benchmark. The relay family has 10 tasks on tallyho, each needing one lesson an earlier agent left. The interrupt family has 6 tasks with a real predecessor cut off halfway. Channels are repo-only, trace, notes and records.

scholion-relay

The relay family as Scholion's harness ran it before the Harbor port, with arms cold, baseline, notes and av. These runs seed the handoff page.

scholion-cold

Four injected bugs in a 20,000-line Rust codebase. It needs about 1 GB of disk per session, so it is run by hand and not tracked weekly.

Run one yourself

git clone https://github.com/vinhqbui/openevaluations && cd openevaluations
uv sync --extra run                                  # Harbor; needs Docker (on Windows, run from WSL2)
uv run harbor run -p datasets/tallyho-cold -a oracle # every reward 1: the tasks are sound
uv run harbor run -p datasets/tallyho-cold -a claude-code -m anthropic/claude-haiku-5-5 -k 3 -o jobs
uv run oe import-harbor jobs/<job> --dataset tallyho-cold && uv run oe validate
