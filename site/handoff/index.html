The handoff benchmark

Agent A worked on a task and stopped. Agent B takes over. What should B be given, and what does it save? Every channel starts from the same frozen predecessor, so only the channel differs.

Channels

repo-only

A's working tree and nothing else. This is the control.

trace

The tree plus A's whole session as a transcript file, /handoff/trace.md: its messages, every tool call in full and the tool output, long output cut.

notes

The tree plus the NOTES.md A was asked to keep as it went, at the repository root.

records

The tree plus A's decisions and dead ends as structured records anchored to code, delivered by Scholion hooks. Not yet on Harbor: B's daemon has to start from A's records.

B's instruction is the task, one fixed sentence saying another agent was stopped partway and its changes are uncommitted in the tree, and for trace and notes one more sentence saying where the artifact is. Nothing else differs between channels.

Two families. In interrupt tasks, a real A (Claude Code on Scholion, so one run leaves all four artifacts) is cut at a pre-registered six turns, frozen once, and checked: it must have changed code and left notes and records, must not have solved the task already, and no artifact may contain a trace of the hidden tests (pre-registration). In relay tasks, A is curated: ten lessons, of which one is what B's task needs and nine are noise. Following the Handoff Debt protocol, we report acceptance, cost per accepted task, LLM calls, prompt tokens and, where a task defines them, repeated dead ends.

Results so far

These are relay-family runs recorded by Scholion's own harness, with Claude Code on DeepSeek Flash. The Harbor version of the benchmark, which adds the interrupt family, the trace channel and a second successor agent, has not run yet. Deltas are per session, paired by task against repo-only, with task-stratified 95% bootstrap intervals. Cost per accepted task differs more than cost per session because repo-only sessions fail more often. At 30 sessions per cell, no significance is claimed.
